# Предварительное КП · Модуль поведенческого анализа клиентов (Cloud Plus)

HTML-версия предварительного коммерческого предложения с анимациями: заставка, живая сцена «паттерн клиента → пропуск → уведомление», конвейер обработки, сценарий «чизкейк по вторникам» с журналом событий в макете телефона, чек-лист обследования, таймлайн пилота, риски и вопросы, таблица коммерческих условий.

- Живая страница: https://abmarat11-art.github.io/demo-kp-behavior/
- Без заставки (для печати/скриншота): добавить `?nosplash`
- Один файл `index.html`, без сборки. Поля для заполнения: элементы с `data-field` (заказчик, контактное лицо, телефон/email, состав пилота, срок, стоимость, оплата, срок действия).

## Версии

- `index.html` — документный вариант: одна колонка, таблицы, без карточек и цифр-якорей (18.09, по замечанию «слишком по-ИИшному»)
- `landing.html` — лендинг-вариант в бренде Cake Lab (Montserrat, лента разделов)
- `animated.html` — первая анимированная версия (Unbounded, заставка, живые сцены)
